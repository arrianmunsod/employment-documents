# Professional & Employment Documents

This repository contains my professional documents for employment and career opportunities.

## Documents

| Category | Description |
|---|---|
| **Resume / CV** | Professional background, work experience, technical skills, and qualifications |
| **Certifications** | Copies of earned professional and technical certifications |
| **Transcripts of Records** | Records of earned certifications and professional credentials |
| **Police Clearance** | Document for background verification and employment requirements |
| **Certificates of Employment** | Documents verifying previous and current employment history |
| **Character References** | Professional references who can provide information about my work experience, character, and qualifications |
| **Employment Numbers** | SSS, TIN, Pag-IBIG MID, and PhilHealth Identification Number (PIN) |

## Purpose

These documents are provided for professional reference, employment applications, and verification of qualifications and employment information.
